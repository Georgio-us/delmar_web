# DELMAR GROUP - разбор исходного референса

## Общая система

- Один крупный фотосюжет на первом экране, остальные фотографии привязаны к объектам и материалам
- Тёмный фон используется в hero, баннере запроса и контактах
- Основная поверхность белая, внутренние блоки имеют едва заметный тёплый оттенок
- Акцент один - тёплый оранжевый, без золотых градиентов и дополнительных декоративных фигур
- Скругления ровные, в основном 16–28 px, кнопки имеют форму капсулы
- Заголовки спокойного размера, визуальная иерархия строится на отступах и фотографиях
- Для DELMAR сохраняем шрифт без засечек согласно требованию заказчика

## Компоненты сверху вниз

| Компонент | Устройство в референсе | Применение в DELMAR |
| --- | --- | --- |
| Навигация | Логотип, короткие ссылки, компактная контактная кнопка | Логотип DELMAR слева, ясные разделы, одна кнопка связи справа |
| Hero | Фотография на всю площадь, текст в левой части, панель выбора поверх фотографии справа | Квартиры и новостройки в Одессе, три прямых перехода в панели |
| Главное действие | Тёплая капсула, встроенный белый круг с иконкой | Смотреть объекты |
| Вторичное действие | Прозрачная капсула с белым кругом | Отдельный быстрый опрос |
| Доверие | Светлая горизонтальная плашка в нижней части hero | Опыт, сделки, проверка и сопровождение после подтверждения цифр |
| Выделенный объект | Текст слева, крупная фотография справа, короткие характеристики и метка | Эксклюзив месяца с фотографией и конкретными параметрами |
| Помощь с подбором | Широкий горизонтальный блок с фото, текстом и тремя выгодами | Заявка на подбор |
| Подборки | Ряд коротких карточек с разными линейными иконками | Переключение каталога по сценарию |
| Топ-3 | Три крупных фотокарточки с подписью поверх изображения | Выделенные объекты |
| Каталог | Фильтры и плотная сетка карточек | Пять карточек на широком экране, дополнительные по кнопке |
| Баннер запроса | Тёмная широкая плашка и одно действие | Заявка при отсутствии подходящего объекта |
| Видео и агент | Видео слева, портрет и персональное представление справа | Только при наличии реального видео и подтверждённого специалиста |
| Отзывы | Три фотокарточки с информацией о сделке и текстом | Концептуальный вид до получения настоящих отзывов |
| Материалы | Три статьи с фотографиями и понятным переходом | Кнопка «Читать материал» без отдельно стоящей стрелки |
| Контакты | Тёмный фотоблок и форма в две колонки | Контакты, социальные сети с SVG-иконками, форма |

## Два варианта кнопки

Смотреть на `buttons.html`

- A - точное направление исходного референса, тёплая капсула и белый круг с плотной SVG-стрелкой, основной вариант на сайте
- B - спокойный контур и тёплая деталь, для карточек и менее приоритетных действий
