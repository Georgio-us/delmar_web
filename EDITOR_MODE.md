# Редакционный режим DELMAR

В меню сайта выберите «Вход для редактора». Демо-логин: `editor`; пароль: `delmar-demo`.

После входа появляется панель снизу и кнопки редактирования на эксклюзивах, топ-3 и каталоге. Редактор работает поверх самого сайта. Выйти можно нижней кнопкой «Выйти».

## Возможности

- Добавление и изменение объекта: название, расположение, USD-цена, площадь, комнаты, тип, район, застройщик, описание, фотографии, PDF-презентация, подборки и цель покупки.
- Фотографии: путь `assets/`, HTTP(S)-ссылка или загрузка JPG/PNG/WebP. До 8 фотографий, по 1 МБ. Предпросмотр появляется в форме. Загруженные файлы сохраняются в локальном JSON как data URL; серверная загрузка отсутствует.
- Три эксклюзива: выбор объекта, порядок по местам 1–3, самостоятельные редакционные заголовки, описания, особенность и две подписи на фотографии. Цена, характеристики и фотографии берутся из объекта.
- Топ-3: выбор объекта для каждого места. Повтор одного объекта внутри подборки не допускается.
- Удаление освобождает места объекта в подборках. «Восстановить последний удалённый» возвращает запись и её прежние места, если они ещё свободны. Удалённые записи хранятся в локальной корзине.
- Экспорт JSON: просмотр, копирование и скачивание снимка каталога, подборок и корзины. Импорт в интерфейс пока не добавлен.

## Хранение и границы прототипа

`content-store.js` — граница работы с данными: `ContentRepository.getSnapshot()` и `ContentRepository.save(next)`. Снимок имеет `version: 1`, `properties`, `editorial.exclusives`, `editorial.top` и необязательную `trash`. Объекты связаны стабильными ID; подборки содержат ссылки на них. При сохранении проверяется схема, затем записывается localStorage `delmar-content-v1`; только после успешной записи обновляется страница. Ошибка квоты показывает сообщение и сохраняет предыдущие данные.

До первого сохранения используются демонстрационные данные `property-data.js` и метаданные исходного HTML. После сохранения каталог и топ-3 пересобираются из снимка. Изображение карточки и модалки берётся из одной записи. Открытие карточек и избранное используют делегирование событий, поэтому продолжают работать после добавления/удаления DOM-элементов. Событие `delmar:content-changed` обновляет каталог, фильтры, эксклюзивы и открытую карточку. Пустые места не показываются посетителю; целиком пустые подборки скрываются.

Изменения доступны только в том же браузере и на том же origin. Они не изменяют исходные файлы и не публикуются другим посетителям. Удаление данных браузера удалит локальный снимок; используйте экспорт. Вход — демонстрационное переключение режима с sessionStorage `delmar-editor`. Проверка пароля на клиенте не является защищённой авторизацией. Пароли реальных пользователей не вводятся и не сохраняются.

## Подключение сервера позднее

1. Заменить `EditorSession` серверной авторизацией и сессией; проверять права на каждом серверном изменении.
2. Заменить адаптер localStorage загрузкой/сохранением через API. Текущий `save` синхронный; при переходе на сеть сделать `persistEditor` и вызывающие обработчики асинхронными, с ожиданием результата и состоянием загрузки.
3. Перенести проверку схемы на сервер, добавить контроль версии/конфликтов и серверную корзину. Клиентские проверки оставить для обратной связи.
4. Загружать фотографии в файловое хранилище и хранить URL вместо data URL.
5. Получать публичный снимок каталога с сервера при запуске. Отрисовку карточек, редакционных подборок и общую модалку сохранить.
6. Для пользовательских редакционных текстов добавить отдельные RU/UA-поля. Сейчас новые произвольные тексты сохраняются буквально; имеющийся словарь переводит только известные демонстрационные фразы. Интерфейс редактора пока русский.

## Проверка 1 октября 2026

В IAB на текущем десктопном viewport 1280×720 проверены вход/неверный пароль, создание, повторная правка, сохранение после перезагрузки, изменение общей цены в модалке, выбор топ-3, отдельный заголовок эксклюзива, запрет повторов, удаление объекта из обеих подборок и восстановление. Временный объект удалён из публичного каталога; прежние цены и подборки восстановлены. Проверена загрузка JPG и предпросмотр; сохранение произвольного `javascript:`-URL отклоняется. Экспорт отображает валидный JSON с 25 объектами и двумя подборками по 3 места. Событие скачивания Blob не удалось подтвердить через IAB; предусмотрены просмотр и копирование текста.

`node --check` проходит для `content-store.js`, `editor.js` и `script.js`. Проверка валидатора: 8 случаев — корректный снимок, нулевая цена, опасный URL, повтор в топе, несуществующая ссылка, дробные комнаты, пустой заголовок, повтор ID.

Переключение viewport на 390 px блокируется зависшей прежней тестовой вкладкой IAB (timeout синхронизации debugger); мобильный render новой формы в этом проходе не подтверждён. Мобильные стили предусмотрены: полноэкранный диалог, одна колонка полей, перенос панели редактора и строк списка. Повторная мобильная визуальная проверка остаётся отдельным пунктом QA.

## Сверка дизайна

Принятый ориентир — `references/direction-v2/header-final-desktop.png`; новый вид редактора — `references/editor-mode/editor-desktop.png` (скриншот IAB). Проверены классическая типографика, оливковая палитра, геометрия кнопок, отступы/ширина диалога, фотографии в списке. Исправлено влияние общего сброса `.direction button` на стили новых кнопок. Дизайн посетительской страницы и тексты hero не менялись; новый пункт входа в меню и элементы только активного режима добавлены по запросу. Изображения топ-3 после сохранения берутся из первой фотографии объекта — намеренное приведение карточек к единому источнику данных. Форма редактора не имеет отдельного концепта; продолжает принятую тему сайта.
