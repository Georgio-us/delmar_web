# DELMAR GROUP - локальный дизайн-концепт

Статический сайт на HTML, CSS и JavaScript

```sh
python3 -m http.server 4173
```

Главная страница - `http://localhost:4173/index.html`

Два примера кнопок - `http://localhost:4173/buttons.html`

Разбор референса на компоненты - `REFERENCE_COMPONENTS.md`

## Структура

Страница собрана по переданному визуальному референсу `references/site-structure.png`

1. Первый экран с выбором сценария
2. Крупный объект
3. Короткий блок о подборе
4. Категории недвижимости
5. Три избранных объекта
6. Каталог с фильтрами
7. Баннер запроса
8. Видео и информация об агентстве
9. Отзывы
10. Короткий призыв к связи
11. Материалы о недвижимости
12. Контактная форма

Работают выбор сценария на первом экране, категории, фильтры каталога, мобильное меню и демонстрационная форма

## Данные перед публикацией

Объекты, цены, изображения, результаты, отзывы и статьи показывают только дизайн и требуют замены на подтверждённые данные

Форма не отправляет данные, видео не подключено

Логотип `assets/delmar-logo-reference.jpg` передан как JPG 640 × 640, для финального сайта нужен оригинал в векторе или большем разрешении

На главной странице используется вариант A, близкий к исходному референсу. Вариант B показан отдельно для сравнения, переключателя стиля сайта нет

## Текущий проход по дизайну

- В hero направления ведут напрямую к новостройкам, вторичке и форме продажи
- Быстрый опрос открывается отдельно и применяет фильтры к каталогу
- На широком экране каталог показывает пять объектов, оставшийся открывается кнопкой
- Добавлен блок застройщиков с переходом к отфильтрованным карточкам
- Отзывы получили отдельные концептуальные портреты, материалы открываются в диалоге, расширены контакты и футер
- Тексты отзывов и привязка демонстрационных объектов к застройщикам созданы только для локального макета, перед публикацией нужны реальные данные агентства и права на использование имён и фотографий
- Телефон, e-mail, адрес, соцсети, видео и отправка формы ожидают реальные реквизиты и подключение
- Последний проход возвращает округлые кнопки, спокойные панели и тонкую типографику из исходного референса, убирает декоративную букву на первом экране и дублирование названия агентства
- Стрелки в интерфейсе выполнены SVG, в соцсетях используются иконки Instagram, Facebook и Telegram
- У навигации добавлены переходы при наведении, мобильное меню закрывается по Escape и клику вне шапки
- Секция застройщиков использует новое изображение стройки с краном и фотографии в карточках, изображения концептуальные и не представляют реальные проекты названных компаний

### Карточки объектов и цены

`property-data.js` — единый демонстрационный каталог из 25 объектов с условными ценами в USD, описаниями и двумя фотографиями для каждого. Все цены намеренно вымышленные. Каталог, топ-3 и три эксклюзива открывают общую модалку; совпадающие объекты используют один ID и одинаковые характеристики. Фильтр цены теперь работает по числовому `data-price`.

Закрытие крестиком, Escape или кликом за границами модалки восстанавливает прокрутку страницы. Избранное работает отдельно от открытия объекта. Проверены все 28 входов из каталога/топа (25 уникальных объектов), три эксклюзива, фильтр до $100 000, фотографии, валидация и демонстрационная заявка.
